# NMC 통합 관리 (잔업 · 재고 · 손익)

남명(NMC) 직원이 휴대폰에서 잔업·휴일 근무 시간을 직접 등록하고, 같은 앱에서 재고(생산·출고·반입)와 회사 손익(매입·매출)을 보는 설치형 웹 앱입니다.

## 대표 링크 (하나만 쓰면 됩니다)
https://ndk0102-collab.github.io/nmc-overtime/

첫 화면에서 세 가지로 나뉩니다. '관리자' 표시가 있는 곳은 관리자 비밀번호로 로그인해야 열립니다.

| 구분 | 누구나 | 관리자만 |
|---|---|---|
| 잔업 | 잔업 입력 (`overtime.html`) | 잔업 확인 · 급여 (`admin.html`) |
| 재고 | 생산량: 생산 넣기만 + 색상마다 현재고 크게 (`stock.html`) | 출고량: 날짜별 출고·펼쳐 보기·출고 넣기 (`stock.html?view=out`) · 반입량: 반입 넣기 (`?view=in`) · 전체관리: 현재고·예정·월별·연간·기록·단가 (`?view=all`, 예전 `?admin=1`) — 서버에서도 막음 |
| 손익 | — | 매입·매출·월 손익 (`pnl.html`) |

- 모든 화면 위쪽의 '홈' 버튼은 이 첫 화면으로 돌아옵니다. 화면끼리 바로 가는 링크는 두지 않습니다.
- 예전 개인 링크나 홈 화면 아이콘(주소 끝에 `?l=언어&n=이름`)은 첫 화면에서 바로 잔업 입력(`overtime.html`)으로 넘어갑니다.

## 구조
- 이 저장소에는 화면 파일만 있습니다. 기록은 모두 구글 시트 'NMC 통합 관리'에 저장되고, 서버는 그 시트에 붙은 Apps Script 하나입니다.
- 손익 화면의 회사 숫자(대출·원가·매달 비용)와 거래처 분류 규칙은 서버와 시트에만 있습니다. 관리자 비밀번호로 로그인한 뒤에만 받아옵니다. 이 저장소에 회사 숫자를 넣지 마세요.
- 판매량은 재고 출고 기록에서, 인건비는 급여대장(payroll.js 계산)에서 손익으로 이어집니다.
- `admin.html`(급여 관리)과 `payroll.js`(급여 계산)에도 개인 정보는 없습니다. 급여 자료는 로그인한 뒤 구글 시트에서 받아옵니다.
- 관리자 로그인 열쇠는 그 창(sessionStorage `nmc_pay_token`)에만 있고, 첫 화면·잔업 관리자·재고·손익 화면이 같이 씁니다.
- 화면을 고친 뒤에는 `sw.js`의 `CACHE` 이름(버전)을 올려야 설치된 앱에도 새 화면이 반영됩니다.
